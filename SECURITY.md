# Security Policy

Fn-flow runs entirely on your Mac: audio and text never leave it. It needs Accessibility
permission (for the global hotkey and pasting) and Microphone permission, so security
issues matter.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository
([direct link](https://github.com/PrEEtPatEl44/fn-flow/security/advisories/new)).

Include what you found, how to reproduce it, and the impact you think it has. You'll get a
reply within a few days, and credit in the fix's release notes unless you'd rather not.

## Supported versions

Only the latest version on `main` is supported.
